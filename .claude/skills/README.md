# Skills instaladas (origem: github.com/rtadewald/skills)

Cinco skills de planejamento e arquitetura, adaptadas para este projeto.
Nenhuma delas precisa de chave de API.

| Skill | Para que serve | Quando chamar |
|---|---|---|
| `grill-me` | Entrevista de uma pergunta por vez até o plano estar fechado | Antes de começar uma feature grande |
| `improve-codebase-architecture` | Varre o código e entrega um relatório HTML com oportunidades de refatoração | Quando mexer em certa parte estiver difícil |
| `to-tickets` | Quebra o plano em fatias verticais com dependências, em `docs/tickets/` | Quando a tarefa não cabe numa sessão |
| `handoff` | Resume a sessão para a próxima continuar | Sessão longa ou troca de máquina |
| `to-wireframe` | Wireframe tipado em ASCII ou SVG, de uma imagem ou de um brief | Antes de codar uma tela nova |

Ficaram de fora as skills do repositório que dependem de chave paga (OpenRouter, Gemini,
fal.ai): `to-img`, `openrouter-img`, `nano-banana-pro`, `fal-ai`, `img2html`, `img-to-html`,
`video2html` e `plan-screen`. Também ficaram de fora `animate` e `extract-ds` (apontam para
pastas da máquina do autor) e `context7-mcp` (o servidor Context7 já está configurado).
